os-netboot

Third-party OPNsense pkg repository for the os-netboot plugin.

For full install instructions see the README. Short version:

  1. On your OPNsense shell: fetch -o /usr/local/etc/ssl/os-netboot.pub https://johnwbyrd.github.io/os-netboot/os-netboot.pub
  2. fetch -o /usr/local/etc/pkg/repos/os-netboot.conf https://johnwbyrd.github.io/os-netboot/os-netboot.conf
  3. pkg update -f
  4. On your OPNsense shell: configctl firmware install os-netboot
